Tic-Tac-Toe AI

A Python implementation of the classic Tic-Tac-Toe game with an AI opponent. The AI uses the Minimax algorithm to play optimally against a human player.

⸻

Features
	•	Human vs AI gameplay.
	•	AI plays optimally — it never loses.
	•	Command-line interface for easy play.
	•	Simple and clear Python code, perfect for learning algorithms and game development.
